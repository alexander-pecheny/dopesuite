> **The main repository of this project lives at https://code.pecheny.me/pecheny/dopesuite. All issues should be created there.**

Two apps for ЧГК: [xy](xy/) (encrypted question-editing boards) and
[dope](dope/) (tournament management), on two shared layers.

Released binaries of xy are built and published on the
[GitHub mirror](https://github.com/alexander-pecheny/dopesuite/releases); see
[`xy/docs/selfhosting.md`](xy/docs/selfhosting.md) to run your own instance and
[`docs/adr/0003-releases-are-built-on-github.md`](docs/adr/0003-releases-are-built-on-github.md)
for why they live there.
